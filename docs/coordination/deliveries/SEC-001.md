3. **Persistencia de defaults legados en codigo:** Los defaults en codigo definidos en [`src/server/db.ts:354`](src/server/db.ts#L354) contienen campos legados (incluyendo un PIN legado en codigo). 6. **Limites del alcance:** No se modifico la logica de [`src/server/db.ts`](src/server/db.ts) en esta tarea. Los cambios funcionales para sanear defaults de codigo quedan documentados para tareas posteriores.

### A. Validacion Estructural y Ausencia de Sensibles en `data/gwen_db.example.json`
Comando PowerShell para validar sintaxis JSON y verificar ausencia recursiva de campos sensibles y colecciones con datos:
```powershell
# 1. Parseo de sintaxis JSON
$jsonText = Get-Content -Raw -Path "data/gwen_db.example.json"
$db = $jsonText | ConvertFrom-Json

# 2. Verificacion recursiva de claves prohibidas (pin, password, hash, salt, token, secret)
$forbiddenKeys = @('pinAdmin', 'pin', 'password', 'passwordHash', 'salt', 'token', 'secret')
$foundKeys = [System.Collections.Generic.List[string]]::new()
function Check-Keys($obj, $path) {
    if ($obj -is [PSCustomObject]) {
        foreach ($prop in $obj.PSObject.Properties) {
            if ($forbiddenKeys -contains $prop.Name) {
                $foundKeys.Add("$path.$($prop.Name)")
            }
            Check-Keys $prop.Value "$path.$($prop.Name)"
        }
    } elseif ($obj -is [System.Collections.IEnumerable] -and $obj -isnot [string]) {
        $i = 0
        foreach ($item in $obj) {
            Check-Keys $item "$path[$i]"
            $i++
        }
    }
}
Check-Keys $db "root"
if ($foundKeys.Count -gt 0) {
    Write-Error "Fallo: se encontraron claves sensibles en el fixture: $($foundKeys -join ', ')"
} else {
    Write-Host "OK: Ausencia de claves sensibles verificada."
}

# 3. Verificacion de colecciones sensibles vacias
$emptyCollections = @('users', 'sessions', 'auditLogs', 'appointments', 'clients', 'clientAlerts', 'clientPreferences', 'clientTipsConfig', 'availabilityExceptions', 'notificationLogs', 'promotionUsages', 'clientBenefits')
foreach ($col in $emptyCollections) {
    $count = ($db.$col).Count
    if ($count -ne 0) {
        Write-Error "Fallo: coleccion '$col' tiene $count elementos (esperado: 0)."
    }
}
Write-Host "OK: Colecciones sensibles vacias (count = 0)."

# 4. Verificacion de campos de contacto vacios
if ($db.config.direccion -ne "" -or $db.config.telefono -ne "" -or $db.config.whatsapp -ne "" -or $db.config.instagram -ne "" -or $db.config.email -ne "") {
    Write-Error "Fallo: config contiene datos de contacto/direccion no vacios."
}
if ($db.professionals[0].email -ne "" -or $db.professionals[0].telefono -ne "") {
    Write-Error "Fallo: professional contiene datos de contacto no vacios."
}
Write-Host "OK: Contactos y direccion sanitizados a strings vacios."
```
