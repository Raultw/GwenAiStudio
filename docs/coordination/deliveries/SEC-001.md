3. **Persistencia de defaults legados en codigo:** Los defaults en codigo definidos en [`src/server/db.ts:354`](../../../src/server/db.ts#L354) contienen campos legados (incluyendo un PIN legado en codigo). 5. **Modo de pruebas en memoria:** La opcion `TEST_MEMORY_ONLY` se evalua antes de la guarda de produccion ([`src/server/db.ts:603-608`](../../../src/server/db.ts#L603-L608)), permitiendo omitir PostgreSQL si se activa dicha variable.
6. **Limites del alcance:** No se modifico la logica de [`src/server/db.ts`](../../../src/server/db.ts) en esta tarea ni se probo contra Neon. Los cambios funcionales para sanear defaults de codigo quedan documentados para tareas posteriores.

### A. Validacion Estructural y Ausencia de Sensibles en `data/gwen_db.example.json`
Comando PowerShell para validar sintaxis JSON y verificar de forma estricta la ausencia recursiva de campos sensibles, colecciones no vacias y contactos operativos:
```powershell
$ErrorActionPreference = 'Stop'

# 1. Parseo de sintaxis JSON
$jsonPath = "data/gwen_db.example.json"
if (-not (Test-Path $jsonPath)) {
    throw "No se encontro el archivo $jsonPath"
}
$jsonText = Get-Content -Raw -Path $jsonPath
$db = $jsonText | ConvertFrom-Json

# 2. Verificacion recursiva de claves sensibles (tokenHash o nombres que contengan password, hash, token, salt, secret, pinAdmin)
$sensitivePatterns = @('password', 'hash', 'token', 'salt', 'secret', 'pinadmin', 'tokenhash')
$foundKeys = [System.Collections.Generic.List[string]]::new()

function Check-SensitiveKeys($obj, $path) {
    if ($obj -is [PSCustomObject]) {
        foreach ($prop in $obj.PSObject.Properties) {
            $propNameLower = $prop.Name.ToLower()
            $isSensitive = $false
            foreach ($pattern in $sensitivePatterns) {
                if ($propNameLower.Contains($pattern)) {
                    $isSensitive = $true
                    break
                }
            }
            if ($isSensitive) {
                $foundKeys.Add("$path.$($prop.Name)")
            }
            Check-SensitiveKeys $prop.Value "$path.$($prop.Name)"
        }
    } elseif ($obj -is [System.Collections.IEnumerable] -and $obj -isnot [string]) {
        $i = 0
        foreach ($item in $obj) {
            Check-SensitiveKeys $item "$path[$i]"
            $i++
        }
    }
}

Check-SensitiveKeys $db "root"
if ($foundKeys.Count -gt 0) {
    throw "Fallo: se encontraron claves sensibles en el fixture: $($foundKeys -join ', ')"
}

# 3. Verificacion de existencia y longitud 0 de colecciones sensibles
$emptyCollections = @('users', 'sessions', 'auditLogs', 'appointments', 'clients', 'clientAlerts', 'clientPreferences', 'clientTipsConfig', 'availabilityExceptions', 'notificationLogs', 'promotionUsages', 'clientBenefits')
foreach ($col in $emptyCollections) {
    if ($null -eq $db.$col) {
        throw "Fallo: la coleccion sensible '$col' no existe en el fixture."
    }
    $count = ($db.$col).Count
    if ($count -ne 0) {
        throw "Fallo: coleccion '$col' tiene $count elementos (esperado: 0)."
    }
}

# 4. Verificacion de campos de contacto y direccion vacios en config
if ($null -eq $db.config) {
    throw "Fallo: 'config' no existe en el fixture."
}
if ($db.config.direccion -ne "" -or $db.config.telefono -ne "" -or $db.config.whatsapp -ne "" -or $db.config.instagram -ne "" -or $db.config.email -ne "") {
    throw "Fallo: config contiene datos de contacto/direccion no vacios."
}

# 5. Verificacion de campos de contacto vacios en TODOS los profesionales
if ($null -eq $db.professionals -or ($db.professionals).Count -eq 0) {
    throw "Fallo: no se encontro la coleccion 'professionals' en el fixture."
}
foreach ($prof in $db.professionals) {
    if ($prof.email -ne "" -or $prof.telefono -ne "" -or $prof.fotoUrl -ne "") {
        throw "Fallo: el profesional con id '$($prof.id)' ($($prof.nombre) $($prof.apellido)) contiene datos de contacto no vacios."
    }
}

Write-Host "OK: Validacion completa exitosa. Fixture JSON valido, colecciones sensibles vacias y contactos sanitizados."
```
