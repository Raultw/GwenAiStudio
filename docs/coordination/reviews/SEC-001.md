Corrección solicitada:

- Usar valores vacíos donde el esquema de ejemplo lo permita o placeholders inequívocos no operativos para contactos/dirección. No crear destinatarios reales de pruebas.
- Si el contrato exige un campo sensible, registrar el impedimento del contrato sin afirmar compatibilidad segura ni cambiar comportamiento de aplicación dentro de esta tarea.
